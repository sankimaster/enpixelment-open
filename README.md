# ENPIXELMENT open

Small, self-contained pages for individual ENPIXELMENT looks. Each one is a single HTML file that runs in the
browser, in two versions: WebGPU (the reference) and WebGL 2 (the same picture, for browsers without WebGPU).

## Projects

| Project | What it is |
|---|---|
| [`matrix-pages`](presets/matrix-pages) | A grid of tiles. Now and then one rises on an edge and turns over, like a page, into a free neighbour. |

## Run one

Open `presets/<name>/webgpu/index.html` in a recent Chrome or Edge, or `presets/<name>/webgl/index.html` in any
browser with WebGL 2. Nothing to install: each file has everything it needs.
